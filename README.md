# Internship & Career Guide

A web design project that helps students explore career opportunities, find internships, prepare for applications, and learn from other students' internship experiences.

## 👥 Team

**Team 14**

## 🎯 Project Purpose

Many students have difficulty finding internship opportunities and knowing how to prepare for their future careers.

The **Internship & Career Guide** provides useful information in one website so students can:

* Explore career opportunities
* Find internship opportunities
* Learn about different jobs
* Prepare a CV
* Prepare for interviews
* Read real internship experiences
* Track their internship applications

## 👤 Target Users

Our main target users are:

* High school graduates
* University students
* Students looking for internships
* Students preparing for their first job

## ✨ Main Features

### 🏠 Home

Introduces the website and helps users quickly access the main sections.

### 🔎 Explore

Helps students explore career and internship-related information.

### 💼 Career Job

Provides information about different career and job opportunities in the private and public sectors.

### 📚 Resource

Provides useful career resources, including:

* CV preparation
* Interview preparation
* Internship experiences
* Career advice

### 🎓 Internship

Shows available internship opportunities with information such as:

* Company
* Position
* Sector
* Category
* Location
* Internship details

Users can search and filter internship opportunities.

### 📝 My Applications

Users can check the internships they have applied for and view their application status.

The application flow is:

```text
Apply Now
     ↓
Application Form
     ↓
Application Successful
     ↓
My Applications
     ↓
Application Status
```

The application status can be displayed using a timeline:

```text
Applied → Under Review → Interview → Result
```

## ⚙️ Application System

The application system allows users to:

1. Select an internship.
2. Click **Apply Now**.
3. Complete the application form.
4. Submit the application.
5. See an application success message.
6. Open **My Applications** from the navbar.
7. Check their application status.

For the current front-end prototype, application data can be stored locally in the browser using JavaScript.
